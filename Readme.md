# Bank Management System
## Project Description
This is a simple Bank Management System developed using C++.  
The project allows the user to manage bank clients by viewing, adding, deleting, searching, and updating client records.  
All data is stored using file handling.

## Features
### Client Management
- Show Clients  
  Display all clients.  
- Add Client  
  Add new client.  
- Delete Client  
  Remove client.  
- Update Client  
  Edit client data.  
- Find Client  
  Search for client.  

### Transactions
- Deposit  
  Deposit amount into account.  
- Withdraw  
  Withdraw amount from account.  
- Show Total Balances  
  Display the total balance of all clients.  

### User Management
- Show Users  
  Display all users.  
- Add User  
  Add new user with permissions.  
- Delete User  
  Remove user.  
- Update User  
  Edit user data.  
- Find User  
  Search for user.  

### Permissions System
- Assign specific permissions to users (view clients, add, delete, update, transactions, manage users).  
- Access control with "Access Denied" screen when a user tries to use a feature without permission.  

### ATM System
- ATM Login for clients.  
- Quick Withdraw (predefined amounts).  
- Normal Withdraw (custom amount).  
- Deposit money.  
- Check balance.  
- ATM logout and system logout.  

### User Interface Enhancements
- Colored console screens for different operations (e.g., red for delete, green for deposit).  
- Organized menus: Main Menu, Transactions Menu, Manage Users Menu, ATM Menu.
